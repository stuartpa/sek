# SpecExplorerKit v0.1.2

Self-contained Cord authoring and portable generated tests.

## Highlights

- **Implementation-accurate Cord documentation.** SEK now owns a detailed language reference,
  explicit Supported/Conditional/Parsed-only/Unsupported matrix, advanced authoring guide, and
  operator semantics based on accepted traces, acceptance, alphabets, and product signatures.
- **SEK-owned Agent Skills.** The `sek` Spec Kit extension carries `sek-cord-authoring` and
  `using-sek-to-generate-tests`, including parse-validated Cord assets. Downstream products load
  these resources instead of copying SEK documentation.
- **Portable generated xUnit projects.** `sek generate` snapshots the selected binding and its built
  DLL/`.deps.json` dependencies under `BindingAssets`; generated tests load only that snapshot and
  no longer contain absolute binding paths or an ambient `SEK_BINDING` fallback.
- **Standalone model authoring package.** `SpecExplorerKit.Modeling` is published beside the global
  tool so downstream model projects do not require a sibling source checkout.

## Cord guidance

The new documentation explains and tests:

- precedence and fully parenthesized parses;
- accepted finite traces, reachable prefixes, accepting states, and the empty trace `ε`;
- sequence, choice, repetition, wildcard, negation, loose sequence, and binary permutation;
- exact distinctions among `||`, `|||`, and `|?|`, including full-signature synchronization and
  same-label interleave limitations;
- `bind`, `let`, parameter combinations, probability ordering, constructs, model checking, events,
  return binding, and known conditional/unsupported forms.

## Spec Kit extension

The extension ID is now **`sek`**, matching its existing `/speckit.sek.*` command namespace. The
release asset remains named `spec-kit-sek.zip`.

```bash
specify extension add sek \
  --from https://github.com/stuartpa/sek/releases/download/v0.1.2/spec-kit-sek.zip
```

## Assets

| Asset | Purpose |
|---|---|
| `spec-kit-sek.zip` | Self-contained Spec Kit extension with commands, skills, references, and Cord assets. |
| `SpecExplorerKit.Tool.0.1.2.nupkg` | Cross-platform `sek` .NET global tool. |
| `SpecExplorerKit.Modeling.0.1.2.nupkg` | Model-program runtime package for downstream projects. |

## Install from downloaded packages

```bash
dotnet tool install -g SpecExplorerKit.Tool --version 0.1.2 --add-source <release-folder>
```

Reference the matching model runtime in a model project:

```xml
<PackageReference Include="SpecExplorerKit.Modeling" Version="0.1.2" />
```

See the [documentation](https://stuartpa.github.io/sek/) for the quickstart, Cord reference,
support matrix, operator semantics, conformance, and generated-test workflow.
